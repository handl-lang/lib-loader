# Reference

## Public API

| item | what it is |
|---|---|
| module resolution | map an import path to the module that satisfies it |
| import splicing | bind `import`/`from … import` names into the module scope |
| module chain | walk the resolved dependency chain deterministically |

## Crate

| crate | role |
|---|---|
| `loader` | module loader — pure handl |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # hnl test / plugin integration tests
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
