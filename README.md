# lib-loader

The pure-handl module loader (`loader.hnl`), embedded by `plugin-lib-handl`.

## Layout

```text
src/        the .hnl sources
pkg.hnl     package manifest — modules, deps, description, license
```

## Gate

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```
